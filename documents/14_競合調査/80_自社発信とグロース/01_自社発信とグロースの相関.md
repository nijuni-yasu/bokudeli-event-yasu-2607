Shokujii が「機能開発」と「プロモーション(自社発信)」のどちらを先に打つかの判断材料として、6 サービスの自社発信の量と時期を、公開されている成長指標と並べて相関を読んだ。**判断は人が行う。本書は事実と読みを渡すだけで、決定は [意思決定文書](../60_意思決定/01_獲得・継続に必須な機能の検討.md) 側にある。**

## 要約

1. **「発信を増やしたあとに成長が加速した」と言える時期は、6 サービスのどれでも確認できなかった。** ただし「発信が効かなかった」と言える根拠でもない。発信が少ない時期の成長には、資金調達と報道、コロナ特需、競合の撤退、IT 特化といった強い別要因が同時にあり、発信単独の効果は取り出せない。[推測]
2. **発信が成長に先行した例は Luma の 2020 年だけである。** 創業者の Tweet から約 1 週間で TechCrunch に載った。同時期はコロナ特需で、切り分けられない。Partiful の 2022 年の NYT・The Atlantic は、自社が配信したものではなく、獲得した報道である。Partiful の自社配信のプレスリリースは、確認できた範囲で 2026 年の 2 件だけだった。[事実]
3. **発信は成長のあとに増えている。** Luma の City Leads 募集・40 言語記事・How Luma Works は「大きく伸びている」と述べたあと。Partiful の Substack・登壇・ポッドキャストはダウンロード数のピーク(2024-11)より後。connpass のプレスリリースは公開から 12 年後の 2023-10 から。[事実+推測]
4. **発信を増やしても伸びが鈍い例が 3 つある。** Peatix は 2023〜2025 年にリリースが年 14〜18 件へ増えたが、掲載数の伸びは約半分の速さになった。Eventbrite は 2023 年に広告費を約 3 倍にしたが、有料チケットは +7% で、翌年から -10%、-6%。こくちーずは 2020 年に PR が 4 件あった期間に会員の伸びが鈍った。いずれも手数料、コロナの反動、市場の成熟など別要因が混ざる。[推測]
5. **発信が実際に働いた場面は 4 つに絞れる。** 点火(Luma 2020 の Tweet、Partiful 2022 の報道)、ユーザー発の出来事の増幅(Partiful の Chalamet コンテスト 2024-10)、競合の失策に合わせた刈り取り(Luma の比較ページ 12 本)、B2B の存在表明(connpass 2023〜)である。いずれも、先に受け皿となる製品と、起きた出来事が前提になっている。[推測]
6. **発信の増分効果を示す数値は、6 社とも公開されていない。** 経路別の流入比率、獲得単価、広告の増分効果は出てこなかった。本書の相関はすべて時期の突き合わせで、因果ではない。[事実]
7. **Shokujii への示唆 [推測]**: 機能より先にプロモーションを打つ根拠は、この調査からは得られない。一方、費用のかからない発信を機能開発と並行で進めない理由も見つからない。詳細は [§6](#6-shokujii-への示唆推測)。

## 1. 調査の範囲と限界

### 1.1 見たもの

サービスごとに、次の 5 点を年表にした。

- プレスリリースの年別件数と主要な内容
- 公式 SNS の開設時期・フォロワー数・投稿頻度
- オウンドメディア(ブログ、ガイド、ニュースレター)
- 創業者・経営者個人の発信
- 公開されている成長指標(利用者・主催者・イベント・流通総額・ダウンロード・訪問)

既存文書にある事実([グロースストーリー](../10_概観/02_グロースストーリー.md) のチャネル別分析、[M-1・M-4](../10_概観/03_参加者獲得_機能と施策.md)、[Timeleft の獲得](../70_Timeleft調査/03_獲得と流入経路.md))は再調査せず、必要な箇所だけ参照した。

### 1.2 取れなかったもの

| 項目 | 状況 | 影響 |
| :-- | :-- | :-- |
| Wayback Machine の本文 | 本環境から取得できなかった(取得ツールが対象ドメインを拒否。curl も実行不可)。一部サービスは一覧(CDX)のみ取得 | **フォロワー数の推移はほぼ作れていない。** 時点つきで取れたのは Eventbrite の X の 5 時点(2009-09〜2014-12)だけ |
| X(旧 Twitter) | ログイン壁。代替ミラーも停止または拒否 | Luma・Partiful・Peatix・connpass・こくちーずの X のフォロワー数は [不明] |
| Social Blade | 403 | 同上 |
| PR TIMES の企業ページ一覧 | 本文を読めず、個別リリースの連番を 1 件ずつ取得して数えた(Peatix、こくちーず) | 年別件数は「確認できた範囲」か、連番からの推計 |
| 媒体資料 PDF | 画像のため本文を読めず(Peatix、こくちーず) | PV・流入内訳は [不明] |
| 10-K の広告費注記 | Eventbrite は一部の年だけ。2020・2021・2025 は [不明] | 広告費と有料チケットの対比は 6 年分 |

要求項目のうち「フォロワー数の推移」は、この調査では**満たせていない**。後から Wayback が使える環境で埋められる([§7](#7-未確認事項))。

### 1.3 数値の扱い

- 利用者数・会員数は、ほぼすべて**会社自身の公表値**([自社主張])で、定義が年によって変わる。Peatix は会員数の公表をやめて年間参加者へ切り替え、こくちーずは「会員」「利用者」「ユーザー登録」が混在する。
- 6 社はいずれも生き残っている(Eventbrite は 2025-12 に買収発表)。発信しても伸びずに消えたサービスは、この調査の対象に入っていない。[推測]
- 結論に影響する 3 点は原典で再確認した(2026-10-17)。connpass のプレスリリースは 2023-10 から 2026-08 の 6 件。Partiful の PR Newswire 上の配信は 2026-06-02 と 2026-10-14 の 2 件。Peatix の PR TIMES 初回配信は 2020-05-22。
- それ以外の数値と出典は、サービス別の原本から引いた。個別に再取得してはいない。

## 4. 相関の読み

以降はすべて [推測]。発信量と成長指標は、同時期に動いたか否かを見ただけで、因果は示していない。

### 4.1 パターンごとの整理

| :-- | :-- | :-- |

| **B. 発信が成長のあとに増えた** | Luma(2024 年以降の City Leads・比較ページ・How Luma Works)、Partiful(Substack 2025-09、登壇 2025〜)、Eventbrite(創業者の出演は 2010 年以降に多い)、connpass(2023 年以降のリリース) | 発信は成長の原因というより、成長した会社の振る舞いに見える。成長期より前の発信量が取れていないサービス(Partiful の SNS など)では、この読みは弱い |

### 4.3 因果を言えない理由

- **逆因果**: Eventbrite の X のフォロワーは 2010-10 の約 1.3 万から 2013-01 の約 12.5 万へ約 10 倍、GTS は約 5 倍に伸びた。ただしフォロワーは会社が大きくなった結果でもある。収益を作っていたのは、利用者の共有行動(Facebook 経由の共有 1 回あたり $2.52〜$4.15)だった。
- **共通原因**: コロナ、資金調達、競合の撤退が、発信量と成長の両方を動かす。
- **測定の問題**: 公表指標の定義が途中で変わる。Peatix の会員数は 840 万で止まり、年間参加者に切り替わった。こくちーずは 2023 年に会員登録必須化の記載がある。Partiful の MAU は会社発表と第三者推計で約 6 倍離れる。
- **増分効果の欠落**: 発信を止めた場合との比較がない。広告やキャンペーンの費用と効果が公開されているのは、Eventbrite の広告費だけで、キャンペーン単体の費用は [不明]。
- **生存者バイアス**: [§1.3](#13-数値の扱い) のとおり。

## 6. Shokujii への示唆(推測)

前提は、検索流入が 3 か月で約 645 クリック(2026-07)であること、PR・オウンドメディアは [露出獲得施策](../../13_成長・露出/01_露出獲得施策.md) の P0〜P1 が計画段階であること、集客ループの部品が個別に揃っていて経路別の計測がまだないことである。

### 6.1 順序の判断に使える範囲

- **「プロモーション先行」を支持する証拠は出なかった。** [意思決定 D-1 の見直し条件](../60_意思決定/01_獲得・継続に必須な機能の検討.md)は、自社発信の量と成長に相関が見えれば、機能より先にプロモーション側(露出獲得施策 P0〜P1)を優先する判断もありうる、としている。調査した 6 サービスの範囲では、この「相関が見えた」場合には当たらない。ただし、これは「相関が見えなかった」であって、「効かないと確認できた」ではない。
- **「発信ゼロでよい」とも言えない。** 発信が少なくても伸びた例は、すべて Shokujii にない別要因(競合の撤退、特化した市場、資金調達と第三者報道、ネットワーク効果の厚み)を持っていた。
- **決定は人が行う。** 本書は D-1 の順序を変える・変えないの判断を含まない。

### 6.2 発信なしで伸びた例と Shokujii の差

| 6 社が持っていたもの | Shokujii の現状 |
| :-- | :-- |
| 運営者自身が最大の主催者(connpass の BPStudy) | 自社の開催実績は本調査の範囲外で、別途確認が要る |
| 検索に載る公開ページが主催者の活動で増える構造(こくちーず 約 28 万件、Eventbrite) | 公開在庫が薄い。検索流入は約 645 クリック / 3 か月 |
| 資金調達と、それに伴う第三者報道(Peatix、Partiful 2022) | 同種の露出手段は持っていない。自社発信が第三者報道の代わりになる側面がある |
| 外部ショックの受け皿(コロナ、Tech Week、競合撤退) | 現時点で乗れる外部要因は特定していない |
| 少人数でも回る製品内の導線(Luma 7 人) | 導線の部品は揃っているが、つながっていない(意思決定文書 §0) |

### 6.3 具体的な示唆

1. **経路別の計測を先に置く判断は、この調査と整合する。** 6 社とも経路別比率や獲得単価を公開しておらず、他社の数値を目標にできない。自社で測らない限り、機能と発信のどちらが効いたかは後からも分からない。[意思決定 F-04](../60_意思決定/01_獲得・継続に必須な機能の検討.md) が前提になる。
2. **費用のかからない発信は、機能開発と並行で進められる。** [露出獲得施策](../../13_成長・露出/01_露出獲得施策.md) の P0-1(非課税改正 PR)や P1-1(開催レポート)は工数 XS で、開発の工数を食わない。期待する役割は、点火と増幅に限る。効果は UTM などで測る。
3. **発信は「増幅できる素材」とセットで置く。** 発信が効いた例は、すでに話題になる製品や出来事があった。開催レポートや SNS 投稿文の素材は、意思決定文書の柱 1(F-03)と同じ素材として使える。Partiful のように、ユーザー発の出来事を拾って運営を支援する体制は、費用がかからない。
4. **個人の発信は、唯一の「発信先行」例(Luma 2020)の担い手だった。** 創業者や幹事の個人アカウントでの発信は費用がかからない。ただし Luma は 2020 年のコロナ特需と同時で、単独の効果は分からない。
5. **競合の変化に合わせた比較ページは、費用が小さい刈り取りになりうる。** Luma は Meetup の値上げ、Eventbrite の買収、Partiful の有料化の直後に整備した。Shokujii では、受け皿となる製品と、比較される競合がどこかを先に決める必要がある。効果の数値は非公開。
6. **避けたほうがよい形が 2 つある。** 広告・キャンペーンを先行させる形(Eventbrite の 2023〜2025 年は、広告費を増やした年にも伸びなかった)。リリース件数を積み上げること自体を目的にする形(Peatix の年 14〜18 件は、PR TIMES 上のフォロワーが 8 人で、公表指標の伸びと対応していない)。
7. **食事会に近い事例の発信は、本調査の対象外である。** Timeleft は広告で都市を広げて縮小した([グロースストーリー](../10_概観/02_グロースストーリー.md) の要約 3)。発信量と密度の関係は、今回の 6 社では調べていない。
