## 2. Takeaway

1. [事実] 2011〜2022 の 12 年間、ヘルプサイトのプレスリリースは 0 件。プレスリリースは 2023-10 から(6 件、2026-08 まで)。ビープラウドのニュース欄にも 2012-06 の有料イベント対応を除き connpass の告知は見当たらない。
2. [二次] 成長の説明は発信ではなく、運営者自身の勉強会(BPStudy、2007-09〜)、Python コミュニティでの初期利用、2013 年の「IT 勉強会特化」、通知メール(会場の 8〜9 割が通知経由の事例)、口コミ(参加者が次に主催する際に使い慣れたサイトを選ぶ)に集中している。
3. [二次] 数値は点でしか取れない: 2016-11 に「5 年で 8 万 5,000 人」(代表の発言)、2023-07 時点で月 1,500 件超、2026 年に約 90 万人(自称)。2016〜2026 の途中値は [不明]。
4. [推測] 2023 年以降のプレスリリースは機能追加と共催の告知が中心で、新規獲得の手段ではなさそう。この時期に利用者数が変わったことを示す数値も無い(月 1,500 件超は 2023 年の取材時点と 2026 年で同じ)。発信開始と成長の相関は確認できず。
5. [推測] 「発信していないのに伸びた」は成立するが、専門分野への特化、運営会社の自社イベント、競合の撤退(ATND 2020-01)という、飲食系に簡単には移せない条件が揃っていた。機能先行は妥当でも、発信を完全に省く根拠にはならない。

## 9. 相関の読み

### 9.1 発信がほぼ無い時期(2011〜2022)に効いたとみられる要因

| 要因 | 内容 | 根拠 | 区分 |
| :-- | :-- | :-- | :-- |
| 運営者自身が最大の利用者 | BPStudy を 2007 年から毎月主催。connpass は BPStudy 管理用に開発し公開 | ビープラウド沿革、dotstudio | [事実]/[二次] |
| Python コミュニティでの初期利用 | 社内がつながっていた Python 系イベントで使われ広がった。2012 年に PyCon JP 関係者(鈴木たかのり氏)が参加し、有料決済・参加枠を追加 | dotstudio | [二次][要約] |
| 口コミ(主催者の連鎖) | 参加者が自分で主催するとき、参加経験のあるサイトを選ぶ | dotstudio | [二次][要約] |
| 2013 年の特化 | 「IT 勉強会といえば connpass」というキャッチコピーで対象を絞る | dotstudio | [二次][要約] |
| 通知メール | 会場の 8〜9 割が通知メール経由という事例(のびすけ氏のイベント) | dotstudio 2016-11、CodeZine 9824 | [二次] |
| 主催者向け機能 | 無料、複数管理者、統計、アンケート、API | Persol、SKYSEA | [二次] |
| ブランド認知(第三者) | 比較記事・TECH PLAY の集約・会社四季報業界地図 2023 年版 | classmethod 2018、paiza 2017、Wikipedia | [二次] |

- [事実] ITmedia 2011-12-15 は、BPStudy は初期に「特に宣伝はしなかった」と書いている(要約)。創業者の姿勢は一貫して「集客より作り込み」。
- [事実] Persol(2018)・SKYSEA(2023)・dotstudio(2016)のいずれも、宣伝・広報施策には触れていない(要約)。

### 9.2 他の要因(必ず併記)

- IT 勉強会ブーム(2010 年代前半): 公式データなし。[推測]
- 競合の動き: ATND 閉鎖(2020-01)で Doorkeeper・Peatix は移行キャンペーンを実施。connpass の対応と受け皿効果は [不明]。Zusaar は終了時期を確認できず [不明]。Doorkeeper は 2013-06 設立。
- コロナ(2020〜): オンライン開催が急増(Peatix では常時 4,000 件超・週 8.5 万人、sbbit 2020-09-26)。connpass 単体の件数は検索で取れず、Japan.R の資料(要確認)にオンライン増の示唆のみ。
- API の外部流通: TECH PLAY などが connpass のデータを集約(2018)。検索流入・露出の増加要因の可能性([推測])。
- 運営会社が「connpass をやっている会社」として得る採用・ブランド効果(代表の発言)。広告塔としての位置づけ。

### 9.3 発信を始めた後(2023-10 以降)の変化

- [事実] 発信の中身: 機能リリースと共催の告知。無料機能は同時期に縮小(API 無料廃止予告 2024-02、iOS アプリ終了 2024-05、X 連携縮小 2026-06、有料プラン予告 2026-08)。
- [事実] 数値: 月 1,500 件超は 2023-07 取材時点と 2026 年の自称で同じ。つまり 3 年間に変化を示す公表値が無い(数値の更新漏れの可能性もある)。
- [推測] 2023 年以降のプレスリリースは「新規ユーザーの獲得」ではなく、「大規模カンファレンス主催者・企業への B2B 向けの存在表明」(共催 Sansan・PyCon JP 協賛・有料プラン前の関係づくり)とみるのが自然。
- 結論: 発信開始と利用者数の変化が重なるかは、データ不足で検証できない。時期が重なるという事実も確認できない。相関なし、ではなく「判定不能」。

### 9.4 相関と因果の区別

- 「発信が少ない=伸びる」という因果は言えない。伸びた要因は上の 9.1 の通りで、発信の有無は説明に使われていない(説明変数に入っていない)だけ。
- 逆に「発信しなかったから問題がなかった」とも言えない。特化した分野(IT エンジニア)は情報流通が速く、コミュニティ内の口コミ・API 連携・通知メールだけで届く構造がある。[推測]
